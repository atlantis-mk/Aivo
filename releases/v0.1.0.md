## Compatibility and migration

The repository URL now resolves to a new Public repository identity and root history; existing clones of the former Private repository must be cloned again or migrated explicitly. The desktop package keeps the existing local API/RPC contracts and schema-v9 persistence behavior. This release adds no new data migration, credential migration, or irreversible operation. Existing schema migrations retain their pre-migration backup and rollback behavior.

## Known issues and compensation limits

The macOS and Windows packages are unsigned. macOS notarization and Windows code-signing evidence are unavailable, so users may receive operating-system trust warnings and this release must not be represented as a fully signed distribution. Linux distribution signing is also not configured. R2 objects under `aivo/releases/v0.1.0/` are immutable; correction requires a new version rather than replacement. The source and previous private repository history remain recoverable from the verified local bundles recorded by repository governance evidence.
