# v0.1.0 Aivo 首个公开版本 / Initial Public Release

Aivo 是一款本地优先的 AI Agent 桌面应用。本版本首次提供公开源码与 macOS、Windows、Linux 安装包。

Aivo is a local-first AI agent desktop application. This initial public release includes source code and native packages for macOS, Windows, and Linux.

## 新增 / Highlights

- 公开 Aivo 桌面端与本地 Go Core 源码，采用 `PolyForm-Noncommercial-1.0.0` 许可。
  Public source for the Aivo desktop and local Go Core under `PolyForm-Noncommercial-1.0.0`.
- 提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 原生安装包。
  Native packages for macOS Apple Silicon, macOS Intel, Windows x64, and Linux x64.
- 支持本地项目、对话、模型提供商连接与 Agent 工具工作流。
  Local projects, conversations, model-provider connections, and agent tool workflows.
- 修复跨平台发布阻塞问题，包括并发终端输入与 Windows Core 进程生命周期编译。
  Fixed cross-platform release blockers around concurrent terminal input and Windows Core process lifecycle compilation.

## 安装提示 / Installation notes

本版本的 macOS 和 Windows 安装包尚未签名，Linux 分发签名也未配置。操作系统可能显示“无法验证开发者”、SmartScreen 或类似安全提示。请只从本仓库的正式 Release 下载，核对 SHA-256，并通过系统提供的用户确认流程继续；Aivo 不会绕过系统安全提示或静默安装。

The macOS and Windows packages are unsigned, and Linux distribution signing is not configured. Your operating system may show developer-verification or SmartScreen warnings. Download only from this official Release, verify SHA-256, and continue through the operating system's user-controlled approval flow; Aivo does not bypass security prompts or install silently.

### Known issues and compensation limits

The macOS and Windows packages are unsigned. macOS notarization and Windows code-signing evidence are unavailable, so users may receive operating-system trust warnings and this release must not be represented as a fully signed distribution. Linux distribution signing is also not configured. R2 objects under `aivo/releases/v0.1.0/` are immutable; correction requires a new version rather than replacement. The source and previous private repository history remain recoverable from the verified local bundles recorded by repository governance evidence.
