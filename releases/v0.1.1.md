# v0.1.1 Aivo 可信自动更新 / Trusted Automatic Updates

Aivo v0.1.1 新增可信桌面自动更新：应用可在启动后或由用户手动检查新版本，并在双来源完整性校验后下载对应平台安装包。本版本适用于希望更及时、安全地获取 Aivo 更新的 macOS、Windows 和 Linux 用户。

Aivo v0.1.1 adds trusted desktop updates. The app can check after startup or on demand, then download the correct native package only after cross-source integrity verification. This release is for macOS, Windows, and Linux users who want a safer, more convenient update path.

## 新增 / Highlights

- 应用启动后会非阻塞检查稳定版更新，也可在“设置”中手动检查。
  A non-blocking stable-channel check runs after startup, with an on-demand check in Settings.
- macOS 的 Aivo 应用菜单新增“检查更新…”，可直接打开更新流程。
  The macOS Aivo application menu now includes “检查更新…” for direct access to the update flow.
- 更新同时核对固定 R2 清单和同版本 GitHub Release 的文件名、大小与 SHA-256；任一来源不一致都会拒绝下载或交接。
  Updates cross-check the fixed R2 manifest and same-tag GitHub Release for exact name, size, and SHA-256; any mismatch fails closed.
- 支持后台下载进度、取消和重试。校验完成后仍需用户明确操作，Aivo 不会静默安装或绕过系统安全提示。
  Background downloads expose progress, cancellation, and retry. A verified package still requires an explicit user action; Aivo never installs silently or bypasses OS security prompts.
- 优化更新设置在窄窗口中的换行、按钮与页脚布局。
  Improved wrapping, actions, and footer layout for the update settings on narrow windows.

## 完整性校验 / Integrity

下载 [`SHA256SUMS`](https://github.com/atlantis-mk/Aivo/releases/download/v0.1.1/SHA256SUMS) 后，可用 `shasum -a 256 -c SHA256SUMS`（macOS/Linux）校验文件。Windows 用户可用 `Get-FileHash <文件> -Algorithm SHA256`，并与清单中的摘要比较。

Download [`SHA256SUMS`](https://github.com/atlantis-mk/Aivo/releases/download/v0.1.1/SHA256SUMS) to verify package integrity. The immutable R2 copies and GitHub assets are published with matching SHA-256 digests.

## 安装提示 / Installation notes

本版本的 macOS 和 Windows 安装包尚未签名，Linux 分发签名也未配置。操作系统可能显示“无法验证开发者”、SmartScreen 或类似安全提示。请只从本仓库的正式 Release 下载，核对 SHA-256，并通过系统提供的用户确认流程继续；Aivo 不会绕过系统安全提示或静默安装。

The macOS and Windows packages are unsigned, and Linux distribution signing is not configured. Your operating system may show developer-verification or SmartScreen warnings. Download only from this official Release, verify SHA-256, and continue through the operating system's user-controlled approval flow; Aivo does not bypass security prompts or install silently.

### Compatibility and migration

This release adds the versioned `desktop-update-ipc-v1` capability between Electron main, preload, and the renderer, without changing the local HTTP API, persistence schema, provider credentials, or stored settings. Existing v0.1.0 installations do not contain the updater and must install v0.1.1 manually; v0.1.1 can discover future stable versions. The updater does not downgrade, silently install, or perform an irreversible migration. If R2 and GitHub are unavailable or disagree, the installed application continues running and the user may retry later or install a verified package manually.

### Known issues and compensation limits

The macOS and Windows packages are unsigned. macOS notarization and Windows code-signing evidence are unavailable, so users may receive operating-system trust warnings and this release must not be represented as a fully signed distribution. Linux distribution signing is also not configured. R2 objects under `aivo/releases/v0.1.1/` are immutable; correction requires a new version rather than replacement. Automatic update depends on both the public R2 stable manifest and the matching GitHub Release metadata; transient unavailability or disagreement fails closed and leaves the installed application unchanged.
