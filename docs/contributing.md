## Contributing to this fork

This repository is an independent fork of OpenAI Codex. Please report security
issues privately and never include API keys, access tokens, authentication
sessions, user prompts, private repositories, or other sensitive data in an
issue, pull request, test fixture, or log.

Before submitting a pull request, keep the change focused, describe the user
impact and verification performed, and include tests for behavior changes.
Changes that modify upstream Codex source must preserve its attribution notices
and Apache-2.0 licensing obligations.

## Contributor agreement

There is no standalone CLA in this fork. By submitting a contribution, you
confirm that you have the right to submit it and grant the repository
maintainers the rights needed to distribute it under the license that applies
to the affected files:

- Contributions to Codex-derived files, including modifications to them, are
  contributed under Apache-2.0.
- A new standalone Aivo-specific file may use PolyForm Noncommercial 1.0.0
  only when it is explicitly marked as described in
  [AIVO-LICENSE-NOTICE.md](../AIVO-LICENSE-NOTICE.md).

Submitting a pull request does not transfer copyright or grant commercial
relicensing rights beyond the applicable file license. If maintainers intend to
commercially license a non-trivial third-party Aivo contribution, they must
obtain a separate written contributor agreement before merging it.
