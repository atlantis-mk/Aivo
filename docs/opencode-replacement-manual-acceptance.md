# OpenCode 主要功能替换：桌面人工验收

这份清单只验证桌面端代码开发主流程，不比较 CLI、TUI、SDK、GitHub Action 或产品入口。自动化测试已经覆盖运行时边界；以下项目必须在 Electron 窗口中使用真实 Provider 完成，才能把替换状态从“代码就绪”改为“验收通过”。

## 验收前准备

- 使用一个可随时丢弃修改的 Git 测试项目，不要用包含未备份改动的工作区。
- 准备一个可用 Provider 账号或测试密钥；不要把密钥写入截图、验收记录或项目文件。
- 在测试项目中创建 `manual-acceptance.txt`，内容为 `before`，并确认工作区干净。
- 启动 `pnpm dev`，只在 Electron 窗口中操作。
- 每项记录：日期、项目路径、Provider/模型、Agent、权限模式、实际结果、截图或会话 ID、通过/失败。

## 1. Provider、模型与真实对话

1. 打开测试项目，在模型菜单中选择“添加 Provider”。
2. 点击“刷新目录”，确认出现成功提示，关闭并重新打开后目录仍可使用。
3. 连接真实 Provider 并选择模型。
4. 发送：`读取 manual-acceptance.txt，只回复其中的内容，不修改文件。`

通过标准：回复为 `before`；会话中显示所选 Provider/模型；没有串用其他项目的 Provider 配置；刷新失败时有可读错误且旧缓存仍可使用。

## 2. 读写、命令与子任务

1. 权限模式选择“请求审批”。
2. 发送：`把 manual-acceptance.txt 改成 after，然后读取它确认结果。`
3. 对写入请求点“允许”，确认文件内容为 `after`。
4. 输入 `/review manual-acceptance.txt`。

通过标准：写入前出现审批；允许后任务继续；`/review` 以隔离子任务执行，父会话收到审查结果；子任务不修改文件。

## 3. 权限拒绝与记忆

1. 再请求一次对测试文件的写入，在审批卡片选择“拒绝”。
2. 确认文件未变化，工具调用明确显示拒绝，应用没有卡在运行中。
3. 请求运行一个无破坏性的固定命令，例如 `pwd`，选择“允许”并勾选“记住此命令和 cwd”。
4. 在同一项目、同一权限范围再次请求相同命令，再请求不同命令。

通过标准：拒绝会停止对应调用；被记住的相同命令不重复询问；不同命令仍询问；重启后行为符合界面所声明的保存范围。

## 4. Worktree 生命周期

1. 打开 Worktree 管理，使用自动命名创建一个 Worktree，并绑定当前会话。
2. 创建一个 detached Worktree，确认界面标识为 `detached`。
3. 创建带无害启动命令（例如 `pwd`）的 Worktree：先取消确认一次，再确认创建一次。
4. 在受管 Worktree 中制造已跟踪改动、未跟踪文件和 ignored 文件，执行“重置”。
5. 移除 Worktree；另选一个外部 Worktree，确认它能被发现但不能被 Aivo 当作受管资源破坏。

通过标准：自动分支使用 Aivo 命名；启动命令未经确认不执行；重置后已跟踪、未跟踪和 ignored 改动均清除并恢复基准；活动会话占用时禁止移除；移除受管 Worktree 时其 Aivo 所有分支按界面行为清理；外部 Worktree 有 `external` 标识且受保护。

## 5. 项目隔离与配置生效

1. 准备项目 A、B，在各自项目配置中定义同名但模型或提示不同的 Agent，并配置不同 Provider/模型。
2. 分别打开 A、B，切换到该 Agent，要求它只报告自己的项目名和当前模型。
3. 在 A 中刷新 Provider 目录并切换模型，再返回 B。

通过标准：Agent、默认模型、Provider 和项目指令各自生效；A 的刷新/选择不覆盖 B；来回切换后目录与会话上下文不串项目。

## 6. Agent 交互式终端

1. 权限模式选择“请求审批”，发送：`运行一个交互式命令，先询问 Continue?，收到 yes 后输出 accepted；请根据终端提示完成它。`
2. 批准 `exec_command`，终端出现提示后检查 Agent 是否拿到 `running`、cursor 和 `prompt_detected`，且应用没有等待进程退出。
3. 批准同一进程的 `write_stdin`，确认 Agent 输入 `yes` 后只收到 cursor 之后的新输出并继续到退出。
4. 再运行一个持续等待的交互进程，点击中断会话。

通过标准：终端输出实时出现在活动侧栏；Agent 在提示符/输出静默边界继续推理；输入值不出现在权限记录；中断会结束所属 PTY；其他会话不能读取或写入该进程。
